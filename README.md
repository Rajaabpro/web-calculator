## ✨ Overview

This project is a simple, browser-based calculator. It demonstrates clean DOM manipulation, responsive layout, and incremental UI logic—no frameworks or build tools required.

## 🚀 Features

- **Basic operations**: Add, subtract, multiply, divide
- **Keyboard input**: Type numbers and operators directly
- **Clear actions**: All-clear and backspace/delete support
- **Responsive layout**: Works on desktop and mobile
- **Input validation**: Prevents invalid expressions where possible

---

## 🛠️ Tech Stack

- **HTML5** – semantic markup
- **CSS3** – layout and styling
- **Vanilla JavaScript** – calculator logic and interactions

## 🌟 How to Run

1. Clone or download the project
   ```bash
   git clone <YOUR_REPO_URL>
   cd web-calculator
   ```
2. Open `inde.html` in your browser (double-click or use a local server).

---

## 🧩 How to Use

1. Click buttons or use your keyboard to enter numbers/operators.
2. Press `=` to evaluate the expression.
3. Use `AC` to clear all, or backspace to delete the last entry.

---

## 💡 Customization

- Update colors, spacing, and fonts in `style.css`.
- Extend logic in `script.js` (e.g., parentheses, memory, percent).
